# Week 5_PM — Recorded Presentations & Portfolio Submission

*New session — logistics/submission event, no existing slide deck needed.*

## Purpose
Final session of the block. Students finalise and submit their recorded presentation (OBS-captured, 6–8 min) alongside the written report as a single portfolio submission (see `26-27-B2-ModuleBox/COM7401-Assignment-Brief.md`).

## In-class task
1. **Recording slot** (if not already recorded independently): students who need in-person support use OBS with facilitator on hand for technical troubleshooting.
2. **Submission checklist walkthrough** (10 min):
   - Report (PDF/Word, ~2,500 words, fixed headings) ✅
   - Recorded presentation (MP4, 6–8 min) ✅
   - Both uploaded as ONE combined submission ✅
   - Deadline: end of Session 5 PM ✅
3. **Close-out**: brief module wrap-up, signpost to moderation/feedback timelines.

## Facilitator notes
- This session is logistics-focused, not new teaching content — keep it light-touch and supportive given submission-day pressure.
- Have a technical contingency plan (recording software issues, file size/upload problems) ready before the session.
