# PROVISIONAL four-check reference guide — staff review only

The formal assessment brief names four methodological checks but the workspace has no approved definitions or exemplars. The interpretations below are **draft teaching proposals**, not marking rules. Confirm or replace them before allocating a check to students. Do not publish or mark from this file until approved alongside a consistent rubric.

## Proposed common response standard

For whichever check is assigned, the student states the exact research question from the locked report, names the check, applies it to the proposed question and method, then reaches a bounded conclusion within four minutes ±30 seconds. A strong answer identifies what evidence would support or weaken the proposed finding and acknowledges a real limit. The check tests methodological reasoning, not performance of a completed study.

| Named check | Candidate operational meaning | Practice prompt and defensible response |
|---|---|---|
| **Build vs Finding** | Does the question seek new knowledge, or merely state an artefact-building task? If an artefact is created, identify the evaluation that would produce a research finding. | “Build a phishing-warning browser extension” is a task. “Does a defined warning improve recognition versus the current warning in a simulated task?” can be investigated; accuracy, errors and participant context would bound the claim. This candidate meaning is directly supported by the book's Chapter 4 §4.4, pp. 47–48. |
| **Collapse Test** | Candidate only: temporarily remove the preferred solution or method from the wording. If no investigable problem remains, the question may be an implementation plan disguised as research. | “How can I use an LLM to improve all student support?” may collapse when the LLM is removed. A stronger question states the support problem, population, desired outcome and evidence, then considers whether an LLM is the best method. **This meaning needs owner confirmation.** |
| **No-or-Undefined-Word Test** | Candidate only: challenge a question that can be dismissed with an uninformative yes/no answer or depends on an undefined critical word such as “better,” “effective” or “secure.” Define a measure, context and threshold where appropriate. | “Is the new dashboard better?” is underspecified. Ask better for whom, at what task and against what comparison. A student may defend a yes/no question if it still entails a rigorous comparison and a meaningful interpretation. **This meaning needs owner confirmation.** |
| **“To…” Test** | Candidate only: a sentence beginning “To develop…”, “To explore…” or “To improve…” may be an aim/objective rather than an interrogative research question. Convert the aim to an answerable question and evidence plan. | “To develop a tool for secure file sharing” is an objective. “How do two access-control designs compare on a specified usability and security task?” is a candidate question. **This meaning needs owner confirmation.** |
