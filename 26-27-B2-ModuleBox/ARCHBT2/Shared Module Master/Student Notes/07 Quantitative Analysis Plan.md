# 07 — Quantitative analysis plan

**Goal:** match a numerical analysis to the question, variables and planned data, then interpret it without overclaiming. This supports LO2 and LO3.

First say what each row would represent and what each variable means. A descriptive summary reports a pattern in the data. A comparison asks whether groups or conditions differ. A correlation or regression describes an association under stated assumptions. None of these alone establishes a causal effect. Choose an analysis because it answers the question, not because the software offers it.

**Worked example.** The invented `07 Sample Data.csv` has ten simulated attempts with two warning interfaces. For each attempt it records whether a suspicious message was correctly flagged and the time taken. A simple plan could compare correct flags and describe the distribution of response times by interface. It would not claim the result generalises to all users or that one interface caused a difference without an appropriate design and sample.

State how you would handle missing values, what comparison measure matters, what graph or table would communicate the result, and what would count as an important limitation. If your own proposal is qualitative, practise this example for method literacy but develop the analysis that fits your proposal in the report.

**Glossary:** *variable* — a recorded characteristic; *descriptive statistic* — a summary such as a count or median; *association* — a relationship observed between variables; *inference* — a conclusion beyond the observed cases, requiring justification.

**Your task:** use the sample data to calculate correct-flag counts and median time for each interface. Write two sentences: what the invented data show and what they do **not** establish. Then name the data type and analysis you would plan for your own question.
