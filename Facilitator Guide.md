## 2. Design principle: one spine, two wrappers
**Identical (the spine):** learning outcomes, portfolio output of each session, the single in-class task and its worksheet, pre-session prep, concepts taught, assessment, slides.
**Different (the wrapper):** sequencing, how input is delivered, how groups work, how feedback is given, and where the Zoom-hour functions live.

Rules for staying in sync:
1. Every session ends with the **same artefact** in both threads (a completed worksheet, a draft paragraph, a stated position).
2. If a change is made to Core in a guide, both run sheets are checked.
3. A student who swaps thread (e.g. misses a campus day and catches an online session) must find the same tasks and outputs.

### Online (Thread B) pedagogic toolkit
- **Flip more.** Anything that is pure input and under ~10 min becomes a recorded micro-lecture in the bridge task; live time is for doing and discussing.
- **Short live blocks.** Max ~60 min before a break; no 3-hour lecture, ever.
- **Breakouts of 3–4** with a shared artefact (shared doc, board or worksheet) so work is visible to the tutor.
- **Teaching presence in the rooms.** With fewer students, rotate through rooms and give 2–3 min of individual feedback.
- **Visible participation without forcing cameras:** chat prompts, polls, named check-ins, an exit ticket in each session.
- **Bridge task** (short, 30–45 min, Mon → Sat) that feeds the Saturday session; a **weekend reflection** step (Sat → Mon).
- **Monday-evening energy:** open with a low-load activity; schedule the heaviest thinking in the first half.
- **Recordings:** record live input segments for those who miss it, but design tasks to need attendance.

### Campus (Thread A) pedagogic toolkit
- Protect the one main group task in each session (60 min where possible).
- Physical group work, walking debate, flip charts, peer swaps.
- Zoom hour is for demos, briefings, clinics and Q&A at scale — never small-group tasks.
- Exit ticket on every Zoom so ghosting is visible.
