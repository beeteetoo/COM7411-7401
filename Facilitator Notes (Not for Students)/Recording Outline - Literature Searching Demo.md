# Recording outline — Literature searching demo (~10 minutes)

**Used by:** the Week 2 pre-session Literature Search Task (both COM7401 and COM7411; one recording on each Moodle site).
**Status:** to be recorded. Screen-share demo with voice-over; keep it to one worked topic.

| Time | Segment | What to show |
|---|---|---|
| 0:00–0:45 | Why searching is a method | A search you can describe is a search you can defend; the log is evidence |
| 0:45–2:30 | Build the search string | Break a topic into 2–3 concepts; synonyms with OR; concepts with AND; quotation marks for phrases; wildcard example |
| 2:30–5:00 | Run the search | University discovery search, then one subject database (for example IEEE Xplore, ACM Digital Library or Scopus) and Google Scholar; filters (years, peer-reviewed); reading the first page of results |
| 5:00–6:30 | Backward searching | Open a strong paper, read its reference list, pick one older key source and find it through the library |
| 6:30–8:00 | Forward searching | "Cited by" in Google Scholar or Scopus; choose a recent paper that builds on the anchor |
| 8:00–9:00 | Triage in 2 minutes | Abstract, Methods, year, peer-reviewed, type of paper; spot the stance clue |
| 9:00–10:00 | Keep a log and check references | Fill one row of the search log; verify every reference exists (AI tools can invent citations) |

**Tips:** use a topic from CS, DA or CY that is *not* a likely student topic; show a dead end and how to adjust the string; add captions.
