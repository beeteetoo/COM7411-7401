## 1. Core — identical in both threads

### Students leave with
- An applied attempt at thematic analysis (coding → concepts → axial coding → categories) on a short extract.
- Clarity on how thematic analysis fits (or does not fit) their own design.
- Their **report ready to submit**, with the declaration of software/GAI use.
- Their **oral-defence check** (issued this week by a pre-generated balanced list; working definitions in `Facilitator Notes (Not for Students)/DRAFT - Four Checks Working Definitions.md`, allocation script in `Facilitator Notes (Not for Students)/Tools/allocate_checks.py`).

### Pre-session prep (both threads)
- `Pre-Session Prep/Qualitative_Research_Projects_in_Computi.pdf`, `CritiquingResearchQUAL.pdf`, `QUAL.png`
- Content/narrative/grounded-theory analysis are "other methods you may encounter" reading — **not** taught live.
- Thread B: the qualitative worked-example recording (Week 3→4 bridge).

### Core task
`In-Class Activity/Thematic Analysis Coding Task.docx` — code the short invented extract (or own excerpt for qual/mixed students) through the demonstrated steps; model answer in `Facilitator Notes (Not for Students)/Lecturer Copy - Thematic Analysis Coding Task (model answer).md`. `Qual Cheat Sheet.docx` (a table of collection methods) is a reference for the comparison slide, not the coding task.

### Content delivered live
What qualitative research is · comparison of data collection methods (one table) · Thematic Analysis definition · live worked example (smartphone / elderly users): reading and chunking → coding → concepts → axial coding → categories (Barriers / Opportunities).
The worked example is the strongest teaching sequence in the module — protect it.
